# Como abrir o dashboard (Power BI)

1. Baixe este repositório.
2. Abra `powerbi/construction_cost_dashboard.pbip` no Power BI Desktop.
3. **Página Inicial → Transformar dados → Editar parâmetros** → em **PastaDados**, cole o caminho da pasta `data` do repositório → OK.
4. Clique em **Aplicar alterações** (ou **Atualizar**). O dashboard carrega.
